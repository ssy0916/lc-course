# 常见食材搭配

## 蛋类

- 鸡蛋 + 番茄：经典家常搭配，番茄的酸味能提鲜。
- 鸡蛋 + 韭菜：适合快炒或做馅，韭菜先下锅会出水，应先炒鸡蛋。
- 鸡蛋 + 木耳 + 黄瓜：木须肉的基础组合，可加瘦肉片。

## 肉类

- 猪肉 + 土豆：炖煮类搭配，土豆吸收肉汁后口感绵软。
- 牛肉 + 番茄：番茄的有机酸能帮助牛肉软化，适合炖汤。
- 鸡肉 + 香菇 + 红枣：适合煲汤，味道鲜甜。

## 素菜

- 豆腐 + 白菜：清淡炖煮，适合秋冬季节。
- 西兰花 + 蒜：蒜蓉清炒，焯水 1 分钟再炒能保持翠绿。
- 茄子 + 蒜 + 酱油：茄子吸油，先蒸后炒可以减少用油量。

## 搭配原则

- 荤素搭配：一餐中既有蛋白质也有蔬菜，营养更均衡。
- 味道互补：酸味食材（番茄、醋）适合搭配油腻食材。
- 口感对比：脆的食材（黄瓜、芹菜）搭配软的食材（豆腐、茄子）。
